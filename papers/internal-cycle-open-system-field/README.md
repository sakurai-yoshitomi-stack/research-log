# 内部循環・開放系・場 — Working Paper Series

## 管理体系
- WP-00：親論文
- WP-01〜08：理論分冊
- WP-E01〜03：経済実証系列

## 発見経路
HP制作中の怒り → 内部未来像との乖離 → 体感覚的勾配探索 → AI外在化 → 対人関係 → 感情の開放系 → タイムチェンバー／一時的鎖国 → 内部循環 → 世界との接続 → ZIPANG／再開国 → 場

## 中心命題
- 未来像を直接説明できなくても、距離の変化は身体が教えてくれる。
- 遠ざかる変化は怒り・不快、近づく変化は快・納得として現れる可能性がある。
- AIは内部未来像を高速に外在化する半鏡面的外部系である。
- 感情には内部入力と外部入力があり、相互作用として扱う。
- 外部入力を一時的に弱めると内部循環が見え、循環が豊かになるほど生成物が外へ溢れる。
- 場は内部循環が整った結果として立ち上がる可能性がある。
