# WP-00｜内部循環・開放系・場
## AI・感情・タイムチェンバー・日本・ZIPANGを貫く統合モデル

### 要旨
AIとのWeb制作中に観察された怒りを起点として、内部未来像、体感覚的乖離検出、AIによる外在化、対人関係、内部／外部入力、内部循環、タイムチェンバー、ZIPANG、場を一つの循環モデルとして統合する。

### 1. 発見の起点
AIとのHP制作で生じた「違う」という怒りは、AIそのものより、内部に形成されていた作品の方向性と現在出力との乖離への反応ではないか。

### 2. 内部未来像
未来像は完成図でなくてもよい。余白、密度、静けさ、方向性、リズム等の多次元的方向として存在しうる。

### 3. 体感覚的乖離検出
作品 P(t) と内部未来像 F の距離 D(t) を考える。ΔD<0 なら接近し快・納得、ΔD>0 なら離反し違和感・怒りが立ち上がる可能性がある。

### 4. AIによる外在化
AIは内部像の候補を高速に外へ置く。生成→知覚→体感覚判定→言語化→再生成によって、本人にも明示できない未来像を探索する。

### 5. 閉鎖系から開放系へ
対人では独立した外部が存在する。感情は内部状態・外部入力・相互作用・時間変化の関数として扱う。

### 6. タイムチェンバー
外部入力を一時的に減衰させ、内部循環を可視化・回復する。比喩的には「鎖国」であるが、目的は再開放である。

### 7. 内部循環と余剰
身体、研究、AI、余白、映像、音、経済、食、空間などが内部で接続すると生成が増える。循環が豊かになるほど外へ放出される余剰が増える。

### 8. 自分の中に世界をつくる
内部世界が豊かになるほど、外部世界の同型構造を検出する接点が増える。

### 9. ZIPANG
ZIPANGは海外評価に合わせて日本を加工する装置ではなく、内部循環から生まれたものを世界へ開く再開国装置である。

### 10. 場
内部循環が整うと方向性、関係性、リズム、美意識、余白が相互作用し、場が立ち上がる。

### 統合循環
余白 → 外部入力の減衰 → 内部観測 → 内部未来像 → 体感覚的勾配探索 → 内部循環 → 生成 → 余剰 → 外部放出 → 場 → 感応 → 新たな入力 → 再循環。

### 結論
目指すのは閉鎖でも無制限な開放でもない。「内部を持った開放系」である。
