# 内部用タグ設計ルール v3.0

※ 内部運用専用  
※ 更新・書き換え・削除可  
※ 2026-09-29確定分類対応  
※ 本ファイルは公開リポジトリ上に保存する内部運用仕様である

内部タグは分類や評価のためではなく、研究の進行、揺れ、構造変化を観測するために用いる。

## タグの3レイヤー

- Layer1: 研究構造・観測軸
- Layer2: 研究状態・進行の気配
- Layer3: 運用・ログ種別

## Layer1：研究構造・観測軸

| 内部レイヤー | 内部タグ |
|---|---|
| ① 構造化学（日本流） | `#構造化学` |
| ② 日本OS研究 | `#日本OS` |
| ③ 問いの扱い学 | `#問い` |
| ④ 身体 × 判断 × 恐怖 | `#身体恐怖` |
| ⑤ 流れ・反転現象 | `#流れ反転` |
| ⑥ 契約・境界構造 | `#契約境界` |
| ⑦ 占術・易の構造抽出 | `#占術構造` |
| ⑧ AI × 人間役割分担 | `#AI境界` |
| ⑨ 観測・認知・意味形成 | `#観測認知` |
| ⑩ 情報・記憶・編集循環 | `#情報編集` |
| ⑪ 価値・事業・社会実装 | `#価値実装` |

ルール：

- 1ログにつき主タグ1〜2個を目安とする。
- 必要な場合は複数付与できる。
- 無理に付けない。
- 後から追加・変更できる。
- 外部分類A〜Mとは別軸として扱う。

## Layer3：運用・ログ種別タグ

- `#生ログ`
- `#整理途中`
- `#仮説メモ`
- `#外向け翻訳`
- `#内部確認`
- `#コント回`

原本保存・分類・来歴・版管理・公開処理は、別途META-01〜05で管理する。

## 推奨形式

```yml
sequence: "00001"
external:
  category: A
  subcategories: [A-01, A-04]
internal:
  layer1: [構造化学, 観測認知]
  layer2: [保留, 反転兆し]
  layer3: [生ログ, 重要日]
meta:
  - META-01
```

## 運用原則

- 日次ログ本文は変更しない。
- タグ付けは内部INDEX側で行う。
- タグ変更の履歴を残す。
- タグ数を完成度として評価しない。
- 迷った場合は未分類・保留を許容する。
